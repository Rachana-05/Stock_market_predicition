Quantum ML — ZZFeatureMap Details

ZZFeatureMap Architecture

What is ZZFeatureMap?

ZZFeatureMap is a Qiskit quantum feature map that encodes classical data into quantum states using Hadamard gates and ZZ interactions (two-qubit entanglement).


Circuit structure per layer:

H⊗n → Rz(2x_i) → [CNOT + Rz(2(π-xi)(π-xj))] → repeat


Why ZZ interactions? The term (π-xi)(π-xj) captures second-order feature correlations that classical kernels cannot represent efficiently.


Kernel computation: K(x1,x2) = |⟨φ(x1)|φ(x2)⟩|² where |φ(x)⟩ is the quantum state after ZZFeatureMap encoding.

Project Architecture

Problem Statement

Full-stack stock market prediction using Machine Learning, Deep Learning, and Quantum Machine Learning on NSE-listed Indian stocks. Target: next-day price direction (UP/DOWN) with ≥62% accuracy using a universal multi-stock model.

Data Pipeline
Source: Yahoo Finance (.NS)
Stocks: 10 NSE large-caps
Period: 8 years daily OHLCV
Features: 45 technical indicators
Benchmark: Nifty50 relative features
Validation: Walk-forward (rolling)
